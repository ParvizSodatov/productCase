# ProductCase

Витрина IT-проектов Таджикистана — местный аналог Product Hunt.
Разработчики, студии и компании публикуют проекты, люди голосуют и комментируют,
лучшие попадают в топ дня и недели.

## Структура

- `frontend/` — сайт на Next.js (React + TypeScript)
- `backend/` — API (пока не начат, стек согласовывается)
- `PROJECT.md` — все принятые решения по проекту, читать в первую очередь

## Запуск фронтенда

```bash
cd frontend
npm install
npm run dev
```

Сайт откроется на http://localhost:3000
